# 개똥도 쓸모는 있겠지

쓸모없어 보이는데 묘하게 쓸모 있는 이상한 웹 도구들을 모아두는 프로젝트입니다.

## 공개 사이트

- 홈: `https://jkd04255.github.io/eorimjipjak/`
- 어림짐작: `https://jkd04255.github.io/eorimjipjak/calculator/`
- 맞춤법 교정기: `https://jkd04255.github.io/eorimjipjak/spell-checker/`
- 깜빡: `https://jkd04255.github.io/eorimjipjak/kkamppak/`
- 쉿: `https://jkd04255.github.io/eorimjipjak/siren/`

## 현재 도구

### 어림짐작
가끔 계산을 실수하는 계산기입니다. 실수 확률과 강도를 조절할 수 있습니다.

### 맞춤법 교정기
완벽하게 교정한다고 자신하지만 가끔 맞춤법을 오히려 틀리게 만드는 교정기입니다.

### 깜빡
내용을 가끔 흐리거나 바꾸거나 까먹는 캘린더입니다.

### 쉿
소리 나지 않는 소방 사이렌입니다. 경광등의 긴급도와 가짜 음량을 조절하고 시작·정지할 수 있습니다. 실제 오디오, 음성 합성, 진동은 사용하지 않습니다. Space로 시작·정지, Esc로 정지하며 화면을 떠나면 자동으로 멈춥니다. 움직임 줄이기와 운영체제의 모션 감소 설정을 지원합니다.

`siren/` 아래의 정적 HTML, CSS, JavaScript와 경광등 이미지로 동작합니다. 조절값과 출동 횟수는 현재 페이지에서만 유지합니다. `core.js`의 `settings`에서 긴급도에 따른 빛의 주기와 강도를 조정할 수 있습니다. 음량은 콘셉트상 실제 출력에 영향을 주지 않습니다.

`home/`, `toolbox/`는 최신 루트 홈으로 연결됩니다. 새 도구는 홈의 마지막 ‘새로운 앱 추가 예정’ 카드 앞에 추가합니다.

## 프로젝트 원칙

의도적으로 이상하게 동작하는 기능은 콘셉트입니다. 실제 버그와 구분해서 관리하며, 새 도구는 별도 폴더에 추가하고 루트 홈에서 연결합니다.
