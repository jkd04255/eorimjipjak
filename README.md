# 개똥도 쓸모는 있겠지

쓸모없어 보이는데 묘하게 쓸모 있는 이상한 웹 도구들을 모아두는 프로젝트입니다.

## 공개 사이트

- 홈: `https://jkd04255.github.io/eorimjipjak/`
- 어림짐작: `https://jkd04255.github.io/eorimjipjak/calculator/`
- 맞춤법 교정기: `https://jkd04255.github.io/eorimjipjak/spell-checker/`

## 현재 도구

### 어림짐작
가끔 계산을 실수하는 계산기입니다. 실수 확률과 강도를 조절할 수 있습니다.

### 맞춤법 교정기
완벽하게 교정한다고 자신하지만 가끔 맞춤법을 오히려 틀리게 만드는 교정기입니다.

### 깜박
내용을 가끔 흐리거나 바꾸거나 까먹는 캘린더로 제작 중입니다.

## 프로젝트 원칙

의도적으로 이상하게 동작하는 기능은 콘셉트입니다. 실제 버그와 구분해서 관리하며, 새 도구는 별도 폴더에 추가하고 루트 홈에서 연결합니다.
