# 어림짐작 — 계산 실수하는 계산기

실수 확률을 조절할 수 있는 반응형 웹 계산기입니다. HTML 파일 하나에 디자인과 JavaScript가 들어 있습니다. 별도 설치, 외부 라이브러리, API 키, 데이터베이스가 필요 없습니다.

## 파일과 실행

- 전체 실행 코드: `dist/index.html`
- Windows 예시 위치: `D:\Projects\eorimjipjak\dist\index.html`
- 파일을 더블 클릭해 Edge, Chrome, Firefox 등 최신 브라우저로 여세요.
- 터미널 명령은 필요 없습니다. 화면에 어림짐작 계산기와 실수 확률 설정이 보이면 정상 실행입니다.
- 선택 사항: `dist` 폴더에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000`을 열어도 됩니다. 종료는 Ctrl+C입니다.
- 다른 웹 호스팅을 사용할 때는 `dist` 안의 `index.html`을 사이트의 첫 화면으로 업로드하면 됩니다.

## 기능

- 사칙연산, 소수, 양수/음수 전환, 퍼센트, 한 자리 삭제, 전체 초기화
- 곱셈과 나눗셈을 덧셈과 뺄셈보다 먼저 계산
- 실수 확률 0~100%, 기본 30%: 계산마다 독립적으로 결정하며 장기 실수 비율을 보장하지 않습니다.
- 사소한 실수: 마지막 유효 자릿수 부근의 덧셈/뺄셈
- 과감한 실수: 자릿수, 부호 또는 연산 기호 혼동
- 정답 확인: 원래 입력식의 정상 계산 결과와 실수 이유 표시
- 키보드: 숫자, 소수점, + - * /, %, Enter 또는 =, Backspace, Esc 또는 Delete
- 모바일 화면과 키보드 접근성 지원

## 동작 기준

- 0%이면 의도적으로 틀리지 않습니다. 100%이면 계산 가능한 입력의 표시 결과가 정답과 항상 다릅니다. 0 나누기와 숫자 범위 초과는 실수 연출 없이 실제 오류로 안내합니다.
- 같은 결과에서 =를 다시 누르면 재추첨하지 않습니다. 새 숫자나 연산을 입력하고 =를 눌러야 새 계산입니다.
- 결과 뒤에 연산을 이어가면 화면에 표시된 수를 사용합니다. 이전의 틀린 답을 몰래 정답으로 바꾸지 않습니다. 정답 확인도 현재 입력식에 대한 결과입니다.
- 확률과 강도 변경은 다음 계산부터 적용됩니다. 새로고침하면 기본 설정으로 돌아갑니다.
- 200 + 10%는 220, 200 - 10%는 180, 200 × 10%는 20, 단독 10%는 0.1입니다. 여러 항 뒤의 덧셈/뺄셈 퍼센트는 앞부분 전체의 계산값을 기준으로 합니다.
- 숫자 입력은 최대 12자리, 계산 결과는 유효숫자 12자리로 정리합니다. 내부는 JavaScript Number이므로 임의 정밀도 수학 도구가 아닙니다.
- 데이터나 계산 내역은 저장하거나 전송하지 않습니다.

## 수정 위치

- 색상과 레이아웃: HTML 위쪽의 `style`
- 정상 계산: `AlmostMath.evaluate`
- 실수 종류와 크기: `AlmostMath.makeMistake` 내부 로직
- 확률 적용: `AlmostMath.calculate`
- 버튼과 화면 동작: `calculator-app` 스크립트
- 기본 확률: range의 value, 초기 state.probability, 마지막 setProbability(30)를 함께 수정하세요.

## 검증 범위

배포 전 JavaScript 구문, 사칙연산·우선순위·소수·퍼센트, 0 나누기·범위 오류, 실수 확률 0%/100%와 표시 결과의 차이를 확인합니다. 실제 브라우저의 시각적·터치 동작 검사는 별도로 수행하지 않았습니다.
