# 맞춤법 교정기 v0.3

어림짐작과 같은 디자인 계열로 만든 장난형 맞춤법 교정기입니다.

## 콘셉트
- 사용자는 `거의 완벽함`, `완벽함`, `매우 완벽함` 중 하나를 선택합니다.
- 더 완벽한 옵션일수록 실제로는 더 많은 맞춤법 실수를 섞습니다.
- `있습니다 → 있읍니다`, `합니다 → 함니다`, `안녕하세요 → 않녕하세요`, `맞춤법 → 맞춤뻡`처럼 일부러 킹받는 쉬운 오답도 포함합니다.

## 실행
`spell-checker/index.html`을 브라우저에서 열면 됩니다.

GitHub Pages가 저장소 루트 기준으로 배포되어 있다면 `/spell-checker/` 경로로 접속할 수 있습니다.
